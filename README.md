# info-vwaiolet

Vite + React + Tailwind CSS + shadcn/ui starter.

## Scripts

```bash
npm install
npm run dev
```

```bash
npm run build
npm run lint
```

## shadcn/ui

This project is initialized with `components.json`, the `@/*` alias, global theme tokens, and a starter `Button` component.

Add more components with:

```bash
npx shadcn@latest add card input dialog
```
