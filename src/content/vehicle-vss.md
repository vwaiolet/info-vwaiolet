### Summary

대규모 차량 내부 네트워크 데이터(CAN, SOME/IP) 유효성 수집 가속화부터 AI 엔진 추론 모델 최적화 및 2차 검증 계층 연동까지 E2E 솔루션을 주도적으로 설계하고 안정화함

- 주요 스택: Rust, Python, K3s, Redis
- 도메인: 커넥티드 카, Edge AI

### 플랫폼 아키텍처 아웃라인

K3s 클러스터 기반 호스트 네트워크 환경에서 동작하는 차세대 커넥티드 카 데이터 실시간 수집 및 AI 이상 징후 탐지 플랫폼임
인프라 리소스가 제한적인 차량용 엣지 컴퓨팅 장비 환경에서 실시간 초고속 CAN 프레임을 무손실 수집•필터링하고, 경량 AI 추론 모델과 소형 언어 모델(USAD + SLM)을 결합하여 차량 보안 및 물리 법칙 기반 이상 정밀 검증을 실현하는 고도화된 마이크로서비스 아키텍처를 구현했음

**E2E 마이크로서비스 파이프라인 설계**

전체 아키텍처는 고속의 비동기 스트림 데이터 브로커(Redis Stream & Pub/Sub)를 중심으로 물리 계층부터 사용자 인터페이스 계층까지 철저히 철저히 분산 격리된 서비스 형태로 설계 및 유기적 통합을 달성했음

- 로우 데이터 수집 및 가속: SocketCAN 로컬 인터페이스와 결합하여 고속 패킷을 디코딩하고 Redis Stream에 고집적 분산 발행하는 로직 설계
- 하이브리드 AI 이상 탐지 파이프라인: Anomaly Score를 실시간 계산하는 경량 ONNX 추론 계층과 물리 법칙을 검증하는 SLM 오케스트레이션 계층의 하이브리드 결합
- 상황 전파 및 서비스 인터페이스: 웹 소켓 실시간 브로드캐스팅 및 Uptane/TUF 보안 표준 기반의 펌웨어 OTA 플래싱 서브시스템 구현

### 핵심 기술적 의사결정 및 아키텍처 설계 근거

1. 고속 코어 계층의 Rust 선정       
    지속적인 CAN 버스 스트레스 상황 및 패킷 인입 환경에서 가비지 컬렉션으로 인한 예측 불가능한 지연을 원천 차단하기 위해 수집 계층, 전송 계층, 장치 상태 관리 API를 Rust로 구현하여 메모리 풋프린트를 최소화하고 고성능 처리를 보장했음
2. AI/인터페이스 계층의 Python 도입     
    AI 모델링 유연성과 외부 프로토콜 결합 속도를 최대화하기 위해 SLM 및 SOME/IP 계층에는 Python을 채택했음. 이때 동적 타이핑 언어가 유발할 수 있는 휴먼 에러를 방지하고 유지보수 신뢰성을 극대화하기 위해 정적 입출력 타입 힌트를 전면 명시하여 설계 완성도를 높였음

| 마이크로서비스 명 | 기술 스택 및 프레임워크 | 선정 사유 및 아키텍처적 역할 |
| :--- | :--- | :--- |
| can_raw_streamer | Rust, SocketCAN | 플랫폼의 진입점. 초고속 CAN 로우 이벤트를 무손실 필터링 후 Redis Stream에 초고속 발행하는 저지연 아키텍처 구축 |
| ai_watcher | Rust, ONNX, VSS | CAN 시계열 패턴을 고속 디코딩하고 경량화된 USAD 모델에 주입하여 실시간 1차 이상 점수 탐지 가속화 |
| anomaly_verifier | Python, Ollama, Gemma | 1차 이상 발생 시 20프레임의 컨텍스트를 추출, 물리 법칙 페르소나 기반 SLM 정밀 검증을 수행하여 오탐률을 최소화하는 2차 검증 엔진 |
| someip_service | Python, vsomeip, Ollama | 자연어 명령어를 고성능 차량 제어 SOME/IP 패킷 및 CAN 프레임으로 가변 변환해 전송하는 오토모티브 브릿지 인터페이스 |
| event_sender | Rust, WebSocket | Redis Stream을 지속 구독하고 외부 대시보드 클라이언트에 지연 없이 초고속 가용 WebSocket 브로드캐스팅 수행 |
| ota_client | Python, Uptane/TUF 표준 | 보안 무결성이 검증된 가상 펌웨어 업데이트 패키지를 스케줄링하고 물리 칩 플래싱을 수행하는 코어 유틸리티 |

### 주요 엔지니어링 성과

1. 가변 이벤트 전파 패턴 설계를 통한 대역폭 및 리소스 최적화

    - 차량 내부의 고밀도 대규모 시계열 CAN 데이터 수집 시, 모든 정상 데이터를 상위 서버로 전송하는 전형적인 아키텍처는 심각한 대역폭 과부하와 불필요한 클라우드 컴퓨팅 스토리지 비용 폭증을 유발하는 문제가 존재했음
    - 엣지 컴퓨팅 리소스 한계를 극복하고 네트워크 오버헤드를 극적으로 억제하면서도 비정상 오류 발생 시의 가용 속도를 실시간으로 보장하는 고도화된 트래픽 제어 메커니즘 설계가 요구되었음
    - 가변 주파수 이벤트 전파 패턴을 고안 및 적용했음. 정상 상태의 안전 데이터는 1분 주기로 제한하여 요약 보고하는 하트비트 스트리밍 메커니즘을 구축한 반면, 오류 및 경고 조건 만족 시 지연 제어 없이 수집 계층에서 Redis와 AI 계층을 통해 외부 알림까지 무지연 전송되도록 이벤트 지향 파이프라인 라우팅을 설계했음
    - 대규모 초당 수천 개의 CAN 프레임 강제 주입 스트레스 환경에서도 메모리 고갈이나 시스템 크래시 없이 병목을 자가 제어하며 메커니즘이 안정적으로 동작함을 최종 검증했음

2. ONNX 및 SLM 결합 하이브리드 2단계 이상 탐지 아키텍처 구축

    - 시계열 기반의 단순 머신러닝 이상 탐지는 차량의 급격한 조향이나 정상적인 환경 변화 조건에서 오탐을 유발하기 쉬우며, 이로 인한 잘못된 제어 명령 하달은 차량 보안 및 안전에 치명적인 위험을 초래할 수 있었음
    - 초고속 실시간 1차 탐지 속도를 유지하면서도, 오탐을 수학적•물리적 연관 컨텍스트 내에서 심층 검증할 수 있는 정밀성 중심의 멀티 스테이지 검증 파이프라인 모델이 필요했음
    - Rust 계층에 ONNX를 결합하여 VSS 규격으로 초고속 디코딩된 데이터 흐름을 USAD 모델에 상시 주입하는 1차 경량 가속 엔진을 배치했음. 1차 이상 발견 즉시 20프레임 윈도우의 타임라인 컨텍스트를 스냅샷으로 추출 발행하도록 하고, SLM을 활용해 물리 법칙 페르소나 기반 심층 2차 검증을 동적으로 구동하는 이중 계층 구조를 구현했음
    - 고속 Anomaly Score 연산 흐름을 완전히 확보하는 동시에, LLM 기반 정성적 물리 컨텍스트 검토 로직이 정상 완결되어 실시간 알림 전송 레이어까지 통합 파이프라인 종단간 안정성 및 초저오탐 구조를 입증했음

3. 아키텍처 복원력 설계

    - K3s 환경에서 실행되는 마이크로서비스 특성상 가상 브로커(Redis) Pod의 강제 축출/재시작이나 추론 서브시스템의 일시적 연산 병목 및 타임아웃 발생 시, 전체 수집 파이프라인이 연쇄 크래시되는 약점이 노출 될 위험이 컸음
    - 인프라 장애나 의도적 컴포넌트 유실 환경에서도 시스템 전체가 마비되지 않고 자가 치유 및 유연한 Fallback 동작을 수행하는 상용 수준의 내결함성 코어 로직 완성이 요구되었음
    - 첫째, Rust Core 수집기 내부 레디스 클라이언트 모듈에 비동기 재연결 가용성 패턴을 내재화하여 브로커 단절을 즉시 감지하고 백오프 기반 재연결을 시도하도록 재설계했음. 둘째, SLM 검증 계층에 명시적 인퍼런스 예외 및 타임아웃 예외 처리를 적용하여 SLM 지연 시 시스템 전체가 블로킹되지 않고 안전하게 최신 상태를 정상으로 우선 폴백 처리하는 복원력 로직을 설계했음
    - 의도적인 파드 삭제 수행 시 수집기가 크래시 없이 대기 후 자동 재연결에 100% 성공하는 가용성을 확보했으며, 잘못된 ONNX 모델 강제 주입 시 명시적 RuntimeError 로깅 후 CrashLoopBackOff 진입 처리가 정확히 분리되어 안전성을 증명했음
