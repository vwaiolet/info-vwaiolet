### 1. 데이터 레이크(Data Lake)란?

- 정의: 형태(정형, 반정형, 비정형)에 상관없이 가공되지 않은 원시 데이터(Raw Data)를 일단 저렴하게 다 모아두는 거대한 저장소
- 비유: 마트의 깨끗한 생수(웨어하우스)와 달리, 온갖 물이 일단 한 곳으로 모이는 자연의 거대한 호수와 같음

### 2. 현대 데이터 흐름의 표준 공식

- 데이터 레이크 → (데이터 정제/가공) → 데이터 웨어하우스 흐름
- 이를 ELT(추출-저장-가공) 방식이라고 함

1. 1단계 (Bronze): 원본 데이터를 데이터 레이크에 그대로 저장 (싸고 안전함)
2. 2단계 (Silver): 쓸모없는 데이터를 걸러내고 포맷을 맞추는 정제 단계
3. 3단계 (Gold): 목적에 맞게 표(Table) 형태로 만들어 데이터 웨어하우스에 저장. ※ 단, AI/머신러닝용 비정형 데이터(이미지, 음성 등)는 데이터 웨어하우스를 거치지 않고 데이터 레이크에서 바로 사용되기도 함

### 3. 그 많은 데이터 중 뭐가 뭔지 어떻게 알까?

데이터가 섞여 쓰레기통(Data Swamp)이 되는 것을 막기 위해 지도(인덱스)를 만듦
- 메타데이터: 데이터의 생성일, 크기, 형식 등을 적어둔 꼬리표
- 크롤러 (Crawler): 데이터 레이크를 주기적으로 돌아다니며 데이터를 자동 분석하는 로봇
- 데이터 카탈로그: 크롤러가 수집한 정보를 바탕으로 만든 데이터 도서 검색대(사전). 이를 보고 엔지니어는 데이터의 위치와 정체를 파악함

### 4. 어떻게 자동으로 가공해서 넣을까?

사람의 손을 타지 않고 365일 자동으로 굴러가는 데이터 파이프라인(Data Pipeline)을 활용함
- 지휘자 (Orchestrator): 스케줄러(예: Airflow)가 매일 새벽 정해진 시간에 가공 작업을 명령함
- 가공 엔진 (Engine): 분산 처리 엔진(예: Spark)이 데이터를 읽어 들여 컴퓨터 메모리 상에서 구조를 파악함(Schema-on-Read)
- 변환 및 적재(Transform & Load): 코딩을 통해 필터링, 시간대 통일, 개인정보 마스킹 등의 가공을 거친 뒤, 최종 결과물만 데이터 웨어하우스로 전송함
