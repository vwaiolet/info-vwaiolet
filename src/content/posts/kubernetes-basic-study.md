### 1. 쿠버네티스(Kubernetes)란?

- 한 줄 정의: 수많은 컨테이너(서버 프로그램)를 알아서 관리해 주는 지능형 자율 관리자
- 핵심 기능:
    1. 자가 치유(Self-healing): 죽은 프로그램은 알아서 감지하고 즉시 새로 켜서 부활시킴
    2. 오토 스케일링(Auto-scaling): 접속자가 몰리면 서버 개수를 늘리고, 줄어들면 다시 줄임
    3. 무중단 배포(Rolling Update): 서비스가 멈추지 않도록 서버를 하나씩 순서대로 업데이트함
    4. 로드 밸런싱(Load Balancing): 몰려오는 사용자 요청을 여러 서버로 골고루 나누어 보냄

### 2. 도커 컴포즈 vs 쿠버네티스

| 구분 | 도커 컴포즈 (Docker Compose) | 쿠버네티스 (Kubernetes) |
| :--- | :--- | :--- |
| 비유 | 단 한 대의 푸드트럭 | 전국 규모의 프랜차이즈 본사 |
| 작동 환경 | 내 노트북, 또는 딱 1대의 서버 | 수십~수천 대의 서버를 묶은 거대한 환경 |
| 핵심 목적 | 로컬 개발 및 테스트를 편하게 하기 위함 | 실제 고객이 사용하는 서비스를 절대 죽지 않게 운영하기 위함 |
| 대처 능력 | 컴퓨터가 꺼지면 서비스도 완전히 죽음 | 서버 일부가 망가져도 살아있는 다른 서버로 즉시 자동 이사 |
| 조절 방식 | 개발자가 수동으로 켜고 끔 | 트래픽에 따라 시스템이 알아서 자동 조절 (자동화) |
| 학습 난이도 | 쉬움 | 매우 어려움 (전문적인 공부가 많이 필요함) |
