### 1. 도커 (Docker)

- 개념: 프로그램과 실행에 필요한 모든 환경(라이브러리, 세팅)을 하나로 묶어, 어떤 컴퓨터에서든 에러 없이 똑같이 실행되게 만드는 도구
- 비유: 무역선 컨테이너 (안에 뭐가 들었든 규격화된 상자에 담아 어디로든 쉽게 옮김)
- 해결하는 문제: 내 컴퓨터에선 되는데 왜 서버에선 안 되지? 하는 환경 차이 문제 해결, 프로그램끼리 버전이 엉켜서 발생하는 충돌 해결, 가상머신(VM)보다 훨씬 가볍고 빠름

### 2. 도커 컴포즈 (Docker Compose)

- 개념: 웹 서버, 데이터베이스 등 여러 개의 독립된 컨테이너들을 하나로 묶어, 명령어 한 줄로 동시에 켜고 끌 수 있게 해주는 관리 도구
- 비유: 한 상 차림 지휘자 (여러 요리를 한 번에 준비해서 식탁에 싹 올려줌)
- 해결하는 문제: 매번 터미널에 수많은 명령어를 입력해 가며 컨테이너들을 일일이 켜고 연결하던 번거로움 해결 (docker compose up 한 줄로 끝)

### 도커파일 vs 도커 컴포즈

| 구분 | 도커파일 (Dockerfile) | 도커 컴포즈 (Docker Compose) |
| :--- | :--- | :--- |
| 비유 | 요리 레시피 | 식사 테이블 배치도 |
| 하는 일 | 딱 하나의 프로그램 상자(이미지)를 어떻게 만들지 정의함 | 이미 만들어진 여러 상자(컨테이너)들을 어떻게 조합해서 실행할지 정의함 |
| 주요 작업 | 만들기(Build) | 실행하기(Run) |
| 대상 | 주로 내가 직접 코딩한 프로그램 | 내가 만든 도커파일 + 남이 만든 완성품(MySQL 등)의 조합 |
| 결론 | 도커파일로 개별 상자를 튼튼하게 조립 | 도커 컴포즈로 그 상자들을 모아서 거대한 하나의 서비스를 완성 |
