### 1. 한 줄 요약 및 비유

| 기술명 | 한 줄 정의 | 쉬운 비유 | 주 임무 (Best for) |
| :--- | :--- | :--- | :--- |
| 쿠버네티스 (K8s) | 인프라 자동 관리 도구 | 튼튼한 운동장 / 아파트 건설사 | 서버(컴퓨터) 묶기, 고장 난 서버 교체, 컴퓨터 늘리고 줄이기 |
| 스파크 (Spark) | 대용량 데이터 처리 엔진 | 공장 컨베이어 벨트 | 대용량 데이터 청소, 필터링, 정렬, SQL 분석 |
| 레이 (Ray) | AI/파이썬 분산 처리 엔진 | 자율적인 연구원 팀 | 딥러닝/LLM 학습, AI 모델 서빙, GPU 연산 |
 
### 2. 핵심 요약

1. 아파치 스파크 (Apache Spark)
    - 특징: 메모리(RAM)를 활용한 빠른 속도(인메모리 연산)가 무기임
    - 강점: 방대한 양의 표(Table) 형태 데이터를 칼같이 나누어 정제하는 데 최강임
    - 역할: 빅데이터를 빠르게 정제하고 분석하는 작업을 전담함
2. 레이 (Ray)
    - 특징: 파이썬 친화적(Python-Native)이며, 머신러닝/딥러닝 학습에 최적화 되어 있음
    - 강점: 복잡한 인공지능 학습을 위해 GPU를 효율적으로 쓰고, 메모리에 데이터를 올려둔 채 학습(Stateful)할 수 있음
    - 역할: ChatGPT 같은 거대한 AI 모델을 분산 학습하고 서비스하는 작업을 전담함
3. 쿠버네티스 (Kubernetes)
    - 특징: 여러 대의 서버를 묶어 관리해 주는 인프라 대장임
    - 강점: 프로그램이 죽으면 살려내고, 트래픽이 몰리면 자동으로 컴퓨터를 늘려줌
    - 역할: 스파크와 레이 같은 프로그램들이 안심하고 일할 수 있는 안정적인 환경을 제공함

### 3. 실제 일하는 흐름 (시너지)

이 3가지를 쿠버네티스 -> 스파크 -> 레이 순서의 하나의 거대한 시스템으로 엮어서 씀
```text
[1단계: 인프라 준비](Kubernetes) 컴퓨터 100대를 묶어서 스파크와 레이가 달릴 수 있는 운동장을 만들어 줌
[2단계: 데이터 정제](Apache Spark) 깨끗한 운동장 위에서, 쌓여 있는 테라바이트급 사용자 로그 데이터를 빠르게 청소함
[3단계: AI 모델 학습](Ray) 정제된 데이터를 받아다가 수십 대의 GPU를 써서 똑똑한 추천 AI 모델을 완성함
```

- 요약: 쿠버네티스가 깔아준 판 위에서, 스파크가 원재료(데이터)를 다듬고, 레이가 그 재료로 멋진 작품(인공지능)을 만들어냄
