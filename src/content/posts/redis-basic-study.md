### 하드디스크와 메모리

우리가 흔히 아는 전통적인 데이터베이스(MySQL, PostgreSQL 등)는 데이터를 하드디스크(HDD, SSD)에 저장함
- 장점: 공간이 엄청 넓어서 데이터를 무한정 보관할 수 있고, 전원이 나가도 데이터가 날아가지 않음
- 단점: 읽고 쓰는 속도가 느림

반면, Redis는 데이터를 메모리에 저장함
- 장점: 읽고 쓰는 속도가 빠름
- 단점: 공간이 좁고, 전원이 나가면 데이터가 날아감

### Redis는 데이터를 어떻게 저장할까?

Redis는 데이터를 저장할 때 Key, Value 방식을 사용함
```TXT
[오늘의 날씨 : 맑음]
[베스트셀러 1위 : 해리포터]
```

### Redis는 언제 쓸까?

사용자들이 자주 찾는데, 매번 DB에서 읽어오기엔 시간이 너무 걸릴 때 사용함

1. 캐싱 (Caching): 똑같은 질문에 빠르게 대답함
쇼핑몰 메인 화면의 '오늘의 특가 상품'은 하루 종일 수십만 명이 똑같이 보는 데이터 -> 아침에 한 번만 Redis에 저장해두고 사용자가 요청할 때마다 Redis에서 가져옴
2. 실시간 랭킹 (Leaderboard): 순위표 자동 정리
게임 순위나 실시간 검색어 시스템에서 사용자의 점수를 실시간으로 정렬
3. 로그인 유지 (Session): 로그인 유저 기억하기
넷플릭스 같은 서비스에 로그인하면, 서버는 로그인한 유저를 기억하기 위해 Redis에 정보를 저장함

### Redis의 치명적인 약점

Redis는 데이터를 메모리에 저장하기 때문에 전원이 나가면 데이터가 날아감
그래서 아주 중요해서 절대 잃어버리면 안 되는 데이터는 MySQL 같은 DB에 저장해야 함
